# What is this?
This folder contains IaC codes for building infrastructure for DefectDojo
https://docs.defectdojo.com/en/open_source/installation/installation/

This uses AWS EC2 instances, existing vpc and domain name.

## EC2
- Ubuntu 22.04 LTS
- t3.small/t3.medium
- DefectDojo-projektin oma docker-compose.yml (testaukseen ok, tuotantoon lisäkovennusta)
